- `<font>` 태그 : 폰트 설정 *(현재는 안 쓰는 표현)*

```html
<h1><a href="index.html"><font color="red">WEB</font></a></h1>
```

- `<!- -   - ->` : 주석과 같은 의미 (코드에 사용 X)
- `<style></style>` : CSS 문법에 맞게 처리 → 디자인과 관련된 내용을 포함  → `</head>`앞에 추가

```html
<style>
    a {
        color:red;
    }  
</style>
```

> `<a>` 태그가 붙은 글자들을 red color로 처리해라
> 

⇒ `a{ }` 🟰 선택자 (**Selector**), 이 효과를 누구에게 줄 것인지 선택

⇒ `color:black`; 🟰 선택자에게 지정될 효과 = 선언 = (**Declaration)**

⇒ `color` : Property(속성)

⇒ `red` : Property Value(속성 값)

- style 태그를 직접 사용 → style이 위치한 태그에게 효과를 줄 것이므로, 선택자 불필요
    
    ⇒ `<a href="2.html" style="color:red">CSS</a>`
    

👉 중복 코드를 줄이기 위해서 CSS 사용이 좋아

```html
<li><a href="2.html" style="color:red">CSS</a></li>
```

- `style=””` 🟰 HTML의 속성
- `color:red` 🟰 CSS의 효과

```html
<style>
    a {
        color:green;
        text-decoration: none;
    }    
</style>
```

- `text-decoration:` 🟰 밑줄을 없애기 위해 텍스트에 장식을 없음으로 설정
- `;` 🟰 하나의 description 시작되고 끝나는 것을 구분하기 위한 “구분자”
    
    ⇒ 한 줄에 써도 정상 동작 `{color:green; text-decoration:none;}`
    

```html
<style>
    a {
        color:green; text-decoration: none;
    }    
</style>
```

- 해당 줄만 밑줄로 구분
    
    `text-decoration:underline`
    

```html
<li><a href="2.html" style="color:red;text-decoration:underline">CSS</a></li>
```

- 모든 링크 : 검정
- 방문했던 각자 링크 : 회색
- 현재 링크 : 빨강
- 방문했던 각자 링크의 색을 지정하기 위해 해당 링크들을 그룹으로 묶어야 함
    
    ⇒ `class` 사용
    
    → `class=”saw”` 🟰 클래스 속성 정의 
    
    → `<style> .saw{} </style>`  🟰  선택자 속성 값 클래스로 설정 
    

```html
<style>
    a {
        color:black;
        text-decoration: none;
    }    
    h1 {
        font-size: 45px;
        text-align: center;
    }
    .saw {
        color:gray;
    }
</style>
</head>
<body>
    <h1><a href="index.html">WEB</a></h1>
<ol>  
    <li><a href="1.html" class="saw">HTML</a></li>
    <li><a href="2.html" class="saw">CSS</a></li>
    <li><a href="3.html">JavaScript</a></li>
</ol>
```

```html
<style>
    a {
        color:black;
        text-decoration: none;
    }    
    h1 {
        font-size: 45px;
        text-align: center;
    }
    .saw {
        color:gray;
    }
    .active{
        color:red;
    }
</style>
</head>
<body>
    <h1><a href="index.html">WEB</a></h1>
<ol>
    
    <li><a href="1.html" class="saw">HTML</a></li>
    <li><a href="2.html" class="saw active">CSS</a></li>
    <li><a href="3.html">JavaScript</a></li>
</ol>
```

- `class`라는 속성의 값은 여러 개가 들어갈 수 있고, 띄어쓰기로 구분
    
    🟰 `class=”saw active”` → saw와 active 클래스 두 개 설정 
    
- 하나의 태그에는 여러 개의 속성이 들어갈 수 있고, 여러 개의 선택자를 통해서 하나의 태그를 공동으로 제어 가능
    
    ⇒ 하지만, 나중에 나온 명령어가 영향력이 있음 → “우선순위”
    

```html
#active{
        color:red;
    }
    .saw {
        color:gray;
    }
</style>
</head>
<body>
    <h1><a href="index.html">WEB</a></h1>
<ol>
    
    <li><a href="1.html" class="saw">HTML</a></li>
    <li><a href="2.html" class="saw" id="active">CSS</a></li>
    <li><a href="3.html">JavaScript</a></li>
</ol>
```

- **id 선택자** : #active
- **class 선택자 :** .saw
- **id 선택자 ↔ class 선택자** 경쟁 → id 선택자가 이김
- **class 선택자** ↔ **tag 선택자** 경쟁 → class 선택자가 이김

<aside>
💡 id 선택자 > class 선택자 > tag 선택자

</aside>

- id의 값 ’active’가 한 번 사용되면,  또 사용하면 안돼
    
    🟰 id 값은 단 한번만 등장해야함 🟰 **중복 불가**
    
- **tag 선택자**가 **id 선택자**보다 포괄적
    
    ⇒ 좀 더 구체적인 것이 포괄적인 것보다 **우선순위**를 높임 
    
    ⇒ 예외도 가능하기 때문, 더 효율적
    

> tag 선택자 포괄적 → id 선택자 구체적 → id 선택자 우선순위 ⬆️

### 박스 모델

- `<h1>`태그 🟰 제목 태그 🟰 화면 전체를 쓰는 것이 기본적으로 편리
- 링크 태그 🟰 화면 전체를 쓰면 불편 🟰 자신 Content 크기 만큼만 사용

- 기본 모델

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title></title>
    </head>
    <body>
        <h1>CSS</h1>Cascading Style Sheets (<a href="http://naver.com">CSS</a>) is a style sheet language used for describing the presentation of a document written in a markup language.
    </body>
</html>
```

- 박스 모델

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title></title>
        <style>
					/*
						blcok level element
					*/
            h1{
                border-width: 5px;
                border-color: red;
                border-style: solid;
            }
					/*
						inline element
					*/
            a{
                border-width: 5px;
                border-color: red;
                border-style: solid;
            }
        </style>
    </head>
    <body>
        <h1>CSS</h1>Cascading Style Sheets (<a href="http://naver.com">CSS</a>) is a style sheet language used for describing the presentation of a document written in a markup language.
    </body>
</html>
```

- `<h1>` 태그는 화면 전체를 사용
- `<a>`태그는 자기 자신의 컨텐트 크기만큼 사용
- `/**/` 🟰 CSS 주석

<aside>
  
💡 화면 전체를 쓰는 태그 : **block level element**

</aside>

<aside>
  
💡 자기 자신 컨텐츠 크기만큼 쓰는 태그 : **inline element**

</aside>

- **block level element ↔ inline element**

```html
display:inline;
display:block;
```

- 서로 바꿔서 사용도 가능

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title></title>
        <style>
            h1{
                border-width: 5px;
                border-color: red;
                border-style: solid;
                display: inline;
            }
            a{
                border-width: 5px;
                border-color: red;
                border-style: solid;
								display:block;
            }
        </style>
    </head>
    <body>
        <h1>CSS</h1>Cascading Style Sheets (<a href="http://naver.com">CSS</a>) is a style sheet language used for describing the presentation of a document written in a markup language.
    </body>
</html>

```

‼️ `display:none;` 🟰 해당하는 태그 안보이게

    - `h1, a {}` 🟰 묶어서 같이 속성 설정 가능

- border 중복 코드 제거
    - `border : 5px solid red;` 🟰 한 줄에 표현

```html
<style>
	h1, a{
	  border: 5px solid red;
  }

```

- **`<h1>`의 `<style>` 정의**
    - 컨텐츠와 테두리 사이 여백 🟰 `padding: 20px;`
    - `<h1>`끼리의 테두리 사이의 여백 없애기 🟰 `margin:0;`
        
        ⇒ `margin:20px;` 🟰 20px만큼 간격 만들기
        

```html
<style>
            h1{
                border: 5px solid red;
                padding: 20px;
                margin: 0;
            }
        </style>
```

```html
<style>
            h1{
                border: 5px solid red;
                padding: 20px;
                margin: 0;
                display:block;
                width: 100px;
            }
        </style>
```

⇒ `width: 100px;` 🟰 100px크기만큼 태그 크기 변경

    🟰 **반응형 웹** (반응형 디자인)
    

```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title></title>
        <style>
            div{
                border: 10px solid green;
                font-size: 60px;
            }
            @media(min-width:800px){
            div{
                display:none;
            }
        }
        </style>
	</head>
	<body>

            Responsive
        </div>
	</body>
</html>
```
